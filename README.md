# Luna: Beauty Store Website

A responsive demo store for a skincare brand, designed and built from scratch.

**Live demo:** https://vocal-horse-b3dca4.netlify.app

## Features
- Mobile-friendly layout with a phone menu
- Cart with quantities and a running total in Kenyan shillings
- WhatsApp checkout: the order is sent as a ready-made message
- Product search, category filters and sort by price
- Quick-view popup for each product
- Wishlist hearts that are saved in the browser
- FAQ, reviews, sale banner and scroll animations

## Built with
HTML, CSS and vanilla JavaScript. No frameworks.

## Customize
Change the brand name, products, prices and photos in `index.html`, and the colors at the top of `style.css`. The WhatsApp number is in one `SETTINGS` line in the script.
